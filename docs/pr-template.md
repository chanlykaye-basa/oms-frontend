## 작성 가이드

| 항목 | 작성 기준 |
|------|-----------|
| **이슈 요약** | 사용자/운영 관점의 문제 배경을 한두 문장으로 |
| **작업 이유** | 왜 이 UI 변경이 필요했는지 — UX 근거 또는 요구사항 출처 포함 |
| **변경 내용** | 컴포넌트 나열이 아닌, 인터랙션/상태/레이아웃 변화 중심으로 |
| **중점 리뷰 포인트** | 주문 상태별 분기 렌더링, 비동기 상태(로딩·에러), 접근성, 타입 안전성 |
| **스크린샷** | UI 변경이 있으면 반드시 첨부 |
| **테스트** | E2E 테스트 미작성 시 사유 명시 |
