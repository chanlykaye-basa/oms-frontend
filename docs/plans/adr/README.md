# Architecture Decision Records (ADR)

이 폴더는 OMS 프론트엔드의 아키텍처 결정 사항을 기록합니다.

## 파일 명명 규칙
`ADR-{번호}-{제목}.md`
예: `ADR-001-server-component-우선-전략.md`

## 상태 종류
- **Proposed**: 검토 중
- **Accepted**: 채택됨
- **Deprecated**: 더 이상 유효하지 않음
- **Superseded**: 다른 ADR로 대체됨
